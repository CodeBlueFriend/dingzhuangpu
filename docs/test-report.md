- V1.3 标准几何匹配 6144×3456 像素契约：全身与面部在上，局部横排在下。
- 中文标签目录能区分角色左/右、全身/面部和鞋履角度。
- 未登记的自定义部件不会退回英文 ID；组合器会要求先补充准确中文名称。
- 底部顺序固定为五官在前、鞋履在后，防止移动格子后分区标题与实际内容错位。
- 拼版器拒绝未通过的源图；标签位于图片区外，并通过唯一 `cell_id` 绑定图片格。
- 布局清单保存分区、图片格、标签格、字体、颜色、视角/部件和来源资产。
- 校验器拒绝右侧细节布局、叠字标签、缺失中文标签契约、错误比例、错误白框和缺失核心细节。
- 1024×576 实际拼版烟雾测试验证严格 16:9、四角纯白和中文字体可用。

## 结论与限制

V1.3 已形成从规格规划、Schema 校验、中文标签目录到确定性拼版和布局清单的可运行闭环。三张展示图验证了新版信息结构与标签可读性；它们仍是一次总图生成结果，不能替代正式项目中的“头像 → 基准 → 分视角 → 逐格检查 → 定向修复”。科幻左右不对称装备尤其需要核对每个源单格。
