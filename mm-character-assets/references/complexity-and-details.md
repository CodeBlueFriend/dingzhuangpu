# 复杂度与细节覆盖

六个维度各取 0–2：服装层次、头部造型、纹样材质、配饰道具、左右差异、遮挡背面。总分 0–3 为 `simple`，4–7 为 `medium`，8–12 为 `complex`。

评分只帮助规划，不能覆盖明确要求：

- 用户点名的细节必须进入覆盖表。
- 左右不同必须能看清两侧；不能镜像。
- 复杂后发型必须展示后脑或头饰背面。
- 非核心纹样或扣件已在主视图清楚可见时可合并；`enhanced` 的眉眼、鼻唇和两种鞋履信息不能因此取消。
- 陌生且必需的结构没有参考时保持 `unresolved`，不能直接进入 `spec_locked`。

每个重要部件记录 `part_id / required_by / anatomical_side / attachment_location / visible_in / occluded_in / coverage_cells / detail_priority / reference_source / qa_status`。

细节选择顺序：增强版核心（眉眼、鼻唇、鞋履斜前、鞋履侧面）→ 用户点名与结构必需项 → 主视图看不清的信息 → 装饰性展示。默认丰富板约 8 格，复杂板约 10 格；不为凑数发明配饰，不自动生成服装拆解、隐藏缝线或悬浮零件图。

五官优先从已通过的大幅面部特写裁出；不足时才定向生成并重新核对身份。鞋履优先展示穿着状态，保留裤脚/裙摆与脚踝连接。赤脚角色用足部细节替代并记录 `footwear=none`。
