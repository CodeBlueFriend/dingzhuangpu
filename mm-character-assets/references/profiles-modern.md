# 现代与日常规则

适用于都市、职场、日常、歌手及现代基础造型。

- 优先固定领型、门襟、袖长、袖口、下摆、腰线、裤/裙结构、鞋和饰品位置。
- 简单造型保持克制：白衬衫、素色西装或基础 T 恤不得无故添加项链、耳环、胸针、腰包或印花。
- 职业身份只影响可解释的服装功能，不用脸推断职业。
- 歌手、时尚或舞台造型可增加设计层次，但每个新增构件必须先写入 Costume Spec。
- 现代重装、机能服或明显不对称装备转读 `profiles-special.md`，不能因“现代”而判为简单。

enhanced 默认细节为眉眼、鼻唇、后发型、领口、腰线或下摆、袖口、鞋履斜前和鞋履侧面。现代简单角色也不退回极简板；非核心结构已在全身格清楚时可合并，但五官和鞋履核心格保留。
