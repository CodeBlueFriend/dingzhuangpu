# 输入质量与表现风格

## 身份参考分级

- `usable`：单人、主要五官可辨、无身份冲突，可正常执行。
- `limited`：侧脸、遮挡、浓妆、滤镜或细节不足。保留可见事实，其他项写明限制或补全来源。
- `missing_required`：无人物、多人未指定目标、主要五官不可辨或参考冲突未解决。进入 `blocked`。

像素数不是唯一标准。放大、锐化、去滤镜都不能恢复真实未知五官。清理后的裁片另存为派生参考，不覆盖原图。

每张参考登记 `reference_id / asset_path / role / scope / source / limitations`。服装参考里的人脸不参与身份锁定；身份头像中露出的衣领、耳环只算造型线索，除非用户明确要求全部保留。

## 风格分流

- `photoreal`：自然肤质、真实材质、中性柔光，避免过度磨皮和锐化。
- `illustration_2d`：保持线条、色块、比例和原着色方法，不添加毛孔或摄影术语。
- `stylized_3d`：保持材质、头身比例和角色造型，不自动真人化。
- `custom`：把用户的风格说明原样记录，明确不可变项。

题材与表现风格是两个字段。古装可以是二维，现代也可以是风格化三维。跨风格转换只承诺设计对应，不宣称外观细节完全等同。

V1 深度验证以单人写实人类角色为主。非人形、动物、机械体、群像和动态表情表只能标为扩展尝试，不能宣称已验证支持。
