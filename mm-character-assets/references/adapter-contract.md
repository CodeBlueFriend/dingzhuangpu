# 图像适配器契约

运行前探测并记录：是否支持参考图、参考数量、分次生成、局部编辑、实际尺寸、状态查询、调用预算及返回文件。工具没有的参数不要发送；相同 seed 也不视为身份保证。

请求至少包含 `task_id / spec_revision / view_id / framing / prompt / references / requested_size / edit_target`。每个参考列出 `reference_id / role / scope`。

返回至少包含 `status`（`succeeded / failed / unknown`）、成功时的 `asset_path`、实际宽高、真实工具或模型标识、能力限制、工具确实返回的请求 ID 和用量信息。先写调用账本，再发请求；返回后先验证文件存在和可读，再记成功。

能力降级：

- 多参考且可分次：稳定路径。
- 单参考：先建立组合基准，标记漂移风险。
- 只能一次总图：快速路径，只减少非必需格；无法容纳增强版面部、五官和鞋履时明确能力限制。
- 有局部编辑：只修失败区域；无局部编辑：重生失败单格，不动通过图。
- 尺寸受限：调整横向版式或减少非必需格，不能静默取消面部/五官/鞋履；记录实际尺寸，不把放大称为细节增强。
- 无生成能力：输出提示词任务包。
- 无视觉检查能力：设 `needs_review`，不得声称一致性通过。

超时返回 `unknown` 时，先查询真实状态或检查已有结果；不可确认时记录潜在重复风险，不能无条件重发。
