# 质量验收与修复

每项结果使用 `pass / fail / uncertain`，并记录 `check_id / task_id / spec_revision / expected / observed / evidence / repair_scope`。不要输出未经标定的相似率。

## 硬性失败

- 可见面部明显换人、已观察特征或年龄感被改写。
- 不同视角混入另一套服装、发型、鞋或头饰。
- 数量、挂点、角色左右或连接关系错误。
- 侧面角度错误、背面回头、重复视角、镜像冒充另一侧。
- 裁掉脚、头饰、袖口、拖尾或用户点名结构。
- 明显肢体错误、穿模、悬浮饰品、无效衣物连接。
- 漏掉明确指定的视角或细节。

## 软性检查

检查尺度、光线、肤色、材质、主纹样分区、特写与全身是否同一造型、有效细节像素和标签遮挡。

## V1.3 总图检查

- 宽大于高且默认 16:9，实际尺寸与计划一致。
- 四边白框等宽、连续、不透明 `#FFFFFF`，无标题、图片、阴影或饰品侵入。
- 上方全身与面部主次清楚，底部局部为横向信息带。
- 分区标题与每格中文名称一一对应，无缺字、乱码、空标签、复制错名或左右混淆。
- 标题和标签位于专属留白区，不覆盖人物、服装、鞋履、饰件或白框。
- enhanced 至少有正面/3⁄4/侧面面部，眉眼和鼻唇可辨，斜前/侧面鞋履属于同一双鞋。
- 细节对象占格充分，不用重复缩略图或同一空泛裁片换标签凑数。
- 全身没有被细节栏挤成不可用缩略图；在 100% 查看时结构可读。

脚本可以检查尺寸、比例、白框像素、矩形溢出、标签区和来源 ID；身份、五官、鞋履与服装一致性仍必须视觉检查。

修复顺序：身份 → 整体轮廓 → 服装结构 → 头饰与左右 → 材质纹样 → 版式。身份错误时回到原头像与基准，不继续叠加美化词。

必需格全部通过才能设总图 `pass`；重要不确定项为 `needs_review`；未解决硬失败为 `draft_failed`。背面属于明确设计补全本身不算失败，但必须忠于已固定设计。
