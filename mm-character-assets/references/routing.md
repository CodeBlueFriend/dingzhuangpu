# 路由与冲突优先级

`Profile Set = 题材规则 + 服装结构规则 + 头部造型规则 + 材质规则 + 特殊约束`。

优先级从高到低：

1. 用户明确要求与指定的参考用途。
2. 当前已固定且未被要求修改的版本。
3. 服装或全身参考中可直接观察的信息。
4. 人物小传与剧情文字的合理解释。
5. 保守默认值。

只给头像时，不猜朝代、职业、真实身高或性格；默认使用“现代中性基础造型”，并标记为设计默认。只写“古装女主”时使用“架空古装”，不擅自认定朝代和礼制。只有用户要求具体史实考据时才查询权威资料并记录来源。

用户要求新服装只覆盖旧造型，不覆盖脸部；要求保留头像发型时，题材模板不得改发型。陌生结构优先补参考；允许自由设计时才采用简洁补全。
