# 覆盖、预算与中断续做

## 预算

基础请求数 = 正面全身基准 + 必要面部基准 + 缺少的全身/面部视角 + 不能裁片复用的细节。默认上限为 16 次图像请求、4 次总修复、每单元 2 次修复。网络重发也计入账本；切换生成策略不重置预算。

基础计划已超上限时，先删非必需展示并调整布局。必需内容仍装不下时停止生成并解释冲突。

## 恢复

每项任务保存 `task_id / spec_revision / reference_fingerprints / prompt_fingerprint / status / asset_path / qa_result / attempt_count`。恢复时先检查规格、输入指纹和文件可读性；复用相同修订下 `qa_result=pass` 的单元。指纹只能证明输入未变，不能证明视觉质量。

## 依赖失效

- 换耳环：只失效可见耳环的视角和特写。
- 换发型/头饰：失效所有可见头部视角；遮脸时重查身份。
- 换衣服：失效正面基准、全部全身与服装细节。
- 新增背面：保留旧通过图，只新增背面及关联细节。
- 改脸：更新身份版本，失效全部面部可见视角。
- 只改版式/标签：只重组总图。

总图纯排版最多修复 2 轮。若根因是人物或服饰，回到受预算约束的图像修复，不能靠裁切掩盖失败。
