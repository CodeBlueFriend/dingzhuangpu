# 视角与布局

## 请求模式

- `auto`：简单/中等默认 `front + left_profile + back`；复杂且存在信息缺口时加入 `right_profile` 或 `left_three_quarter`。
- `three_view`：恰好三张全身，默认正面、角色左侧面、背面。可有面部/细节格；`body_only` 时不得有任何特写。
- `multiview`：未指定数量时默认四张；第四张按双侧差异或层次选择。
- `custom`：严格遵守用户角度和数量，先解决重复或矛盾。

`front` 正对人物；`left_profile` 相机在角色左侧且鼻尖朝画面左；`back` 不回头露脸；`right_profile` 鼻尖朝画面右。头与躯干方向一致。

## 拍摄规范

全身采用低透视变形、中性站姿、手臂适当离身、浅灰背景和柔和中性光。完整保留头饰、袖口、拖尾和鞋。全身与面部任务分开；小脸不能承担身份验收。

## 画布

标准目标 4096×3072，复杂目标 6144×4096；它们是版式目标，不是生成工具保证。全身区约占 65%–75%，细节通常 2–4 格。输出受限时优先减少非必需格、调整布局或说明限制；插值不等于原生细节增强。

文字与版本号在拼版阶段精确添加。对齐使用身体高度和脚底基线；为头饰、宽袖和拖尾增加留白，不拉伸人物。
