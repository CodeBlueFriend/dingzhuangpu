# V1.3 视角、中文标注与横向白框布局

## 请求模式

- `auto`：简单/中等使用 `front + left_profile + back`；复杂且存在信息缺口时增加 `right_profile` 或 `left_three_quarter`。
- `three_view`：恰好三张全身；`asset_board` 仍默认加入增强版面部和细节，`body_only` 才只有三张全身。
- `multiview`：未指定数量时默认四张；第四张按双侧差异或层次选择。
- `custom`：严格遵守用户角度与数量。

`left_profile` 的相机位于角色自身左侧，鼻尖朝画面左；`right_profile` 鼻尖朝画面右；`back` 不回头露脸。禁止镜像冒充另一侧。

## 默认增强板

最终图为不透明横向 16:9 PNG。四周在画布内部保留等宽纯白框，宽度约短边 2% 并四舍五入到最接近的 8 像素。内区为 `#F4F5F6`：

- 上方约 68.5%：左侧约 62% 放全身视角，右侧约 38% 放正面、左前 3/4、左侧三张面部。
- 底部约 31.5%：横向排列五官、发型/头饰、服饰和鞋履局部；复杂板可在更宽画布放约 10 格。
- 总标题、分区标题和每格中文名称分别位于专属留白区；每格名称默认在图片下方居中。

标准画布 6144×3456，白框 72；受限画布 4096×2304，白框 48；复杂画布 7680×4320，白框 88。画布目标不代表生成工具原生能力，插值不能冒充新增细节。

6144×3456 的几何：内区 `[72,72,6000,3312]`，标题 `[72,72,6000,96]`，全身区 `[72,192,3696,2104]`，面部区 `[3800,192,2272,2104]`，底部细节区 `[72,2328,6000,968]`，底栏 `[72,3320,6000,64]`。换尺寸时同比计算，禁止复用绝对坐标造成溢出。

## 单元要求

全身采用低透视、中性站姿、手臂适当离身、浅灰背景；完整保留头饰、袖口、拖尾和鞋。身体等比例 contain 并按脚底对齐。面部与细节可裁已检查源图，但必须记录裁片来源，主体占格约 60%–85%。

布局清单必须保存 `orientation / aspect_ratio / canvas_size / outer_frame / title_rect / footer_rect / region_rects / section_title_rects / cell_rects / label_rects / cell_labels / labels / source_asset_ids / crop_rects / fit_mode`。每个标签通过唯一 `cell_id` 或 `region_id` 绑定实际内容。

纯三视图仍为横向白框，取消面部和底部细节图片，但保留“全身三视图”分区标题与逐格中文名称；这是显式特殊布局，不是现代简单角色的默认回退。
